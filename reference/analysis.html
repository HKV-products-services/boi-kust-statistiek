analysis

analysis

The computational chunks of the KNMI statistics scripts, one function per R chunk.

Every function returns a dict with the variable names of the corresponding R save() call. Random draws are taken from an RRandom stream (kuststatistiek.rrandom) in the same order as in R; the caller is responsible for calling the chunks in R’s order.

Bootstrap of the omni and directional GW estimates from SEAS5 data.

modelerror None: chunk ‘Bootstrap … WITHOUT model error’ (shape estimated) modelerror dict(theta00bs, theta00dirbs): chunk ‘WITH model error’ (wind: shapes fixed at the perturbed values, stress scaled by exp(rnorm(1)*scalestd) drawn from rng per sample) dir_threshold: sample fraction for the directional fits (wind: mthresh, wl: kthresh)
