gw

gw

Generalized Weibull (GW) tail estimation and directional tail analysis.

Line-by-line ports of EVTools::FitGW_iHilli, EVTools::qGWdisp, EVTools::h (R package EVTools) esextr.R, collect.R, taildir.R (KNMI R scripts) Index conventions: R is 1-based; comments give the R expression where helpful.

Functions

Name Description
FitGW_iHilli Port of EVTools::FitGW_iHilli (GW tail fit with implicit joint shape/scale solution).
assigncat assigncat.R: logical matrix (len(y) x nbins) of direction-bin membership.
collect collect.R: indices (1-based) of the resampled series, in the order of the original series.
esextr esextr.R: estimates for the thresholds l0 (in the order of l0, NA where absent).
h EVTools::h: (lambda^theta - 1)/theta, log(lambda) for theta ~ 0.
qGWdisp Port of EVTools::qGWdisp: GW quantiles (and standard errors) from location/dispersion/shape.
rank_transform wlt <- -log(index) + log(N+1), index = ranks of -v (ties in order of occurrence).
taildir Port of taildir.R: directional GW tails, consistent with the omni tail.
