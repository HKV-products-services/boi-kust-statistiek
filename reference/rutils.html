rutils

rutils

Small numerical helpers that reproduce R semantics exactly (or to the last bit where possible).

R functions reproduced: approx, signif, quantile (type 7), sum/mean/sd (R accumulates in long double), loess (via scikit-misc, which wraps the same netlib code as R), %*% (reference BLAS summation order), and write.csv / write.table number formatting.
